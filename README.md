# ccl-ui-assets

Runtime image assets for the CCL Command Surface (NON-PRODUCTION PILOT).

- `main_128/`: nine semantic icons
- `fallback_128/`: Vietnamese calligraphy fallback badges
- `action_128/`, `state_128/`: Soái Lệnh and Quyết định action/state icons
- `bg-thuy-mac-wide.webp`: banner background
- `manifest-v1.1.json`: file contract

Pilot assets. The two `state_128/` icons still contain baked-in text at the bottom edge; a clean version is pending.
